# 统一单跑与批处理的输出路径规则

## Context

**问题来源**：在最近的批处理中，`outputs` 根目录下除了 10 个视频子目录外，还多了 2 个孤儿目录：`outputs\_video_course_work\` 和 `outputs\如何处理产品异议_技术证据稿_assets\`。

**根因**：单跑模式和批处理模式的产物路径规则不一致：

| 视角 | 单跑模式当前行为 | 批处理模式当前行为 |
|------|----------------|------------------|
| 最终产物（讲义、证据稿、JSON） | 散在 `output_dir\` 根下 | 进 `output_dir\<标题>\` 子目录 |
| work 目录 | `output_dir\_video_course_work\<标题>\` ← 孤儿 | `output_dir\<标题>\_video_course_work\<标题>\` |
| assets 目录 | `output_dir\<标题>_技术证据稿_assets\` | `output_dir\<标题>\<标题>_技术证据稿_assets\` |

代码位置：`run_video_course_pipeline.py:397-415`（单跑路径定义），`batch_video_output_dir`（[L157-170](file:///d:/AI_Coach/preprocessing/video-course-to-markdown-skill/video-course-to-markdown/scripts/run_video_course_pipeline.py#L157-L170)，批处理路径分配）。

**目标**：让单跑模式也自动产出 `output_dir\<标题>\` 结构，从根上消除孤儿。这是用户已确认的 breaking change，同步更新 SKILL.md 第 111 行契约。

## 核心思路

**关键挑战**：批处理父进程通过 `build_batch_child_command` 已经把 `outputs\<标题>\` 作为 `--output-dir` 传给子进程（[run_video_course_pipeline.py:246](file:///d:/AI_Coach/preprocessing/video-course-to-markdown-skill/video-course-to-markdown/scripts/run_video_course_pipeline.py#L246)、[L173-200](file:///d:/AI_Coach/preprocessing/video-course-to-markdown-skill/video-course-to-markdown/scripts/run_video_course_pipeline.py#L173-L200)）。如果 `main()` 无条件加 stem 嵌套，批处理会双重嵌套变成 `outputs\<标题>\<标题>\`。

**解法**：加一个隐藏的 CLI flag `--batch-mode`，批处理父进程显式传给子进程。子进程在 `main()` 检测到这个 flag 就跳过 stem 嵌套（父进程已分好子目录），单跑模式不传 flag，自动加 stem 嵌套。

## Breaking change 说明

- **影响**：所有调用 `run_video_course_pipeline.py` 单跑模式的用户脚本/工作流，产物路径从 `outputs\<标题>_xxx.md` 变成 `outputs\<标题>\<标题>_xxx.md`。
- **缓解**：SKILL.md 第 111 行契约同步更新，旧产物可手动移动到新结构，或直接重跑（checkpoint 会复用上游产物，只重写最终产物）。
- **批处理用户不受影响**：批处理模式路径行为完全不变。
